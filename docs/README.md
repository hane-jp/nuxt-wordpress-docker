# 初学者向け補足マニュアル

このマニュアルは、DockerやGitHubをまだ使ったことがない方が、このスターターを自分のPCで表示するまでを補足するものです。

最初からすべてを覚える必要はありません。まずは「Docker Desktopを起動する」「ファイルを取得する」「コマンドを実行する」の3つができれば試せます。

## 目的別の案内

| やりたいこと | 読むページ |
|---|---|
| 最短で画面を表示したい | [はじめてのセットアップ](getting-started.md) |
| Dockerの役割や基本操作を知りたい | [Docker Desktopの準備と基本操作](docker-basics.md) |
| GitHubアカウントを作らずに試したい | [GitHubアカウントなしで始める](github-without-account.md) |
| エラーや表示されない問題を解決したい | [トラブルシューティング](troubleshooting.md) |
| 用語の意味を確認したい | [用語集](glossary.md) |

## おすすめの進み方

1. [Docker Desktopの準備と基本操作](docker-basics.md)でDockerを準備する
2. [はじめてのセットアップ](getting-started.md)の手順で起動する
3. WordPressでサンプル投稿を編集し、Nuxt側の表示を確認する
4. 継続して改修する場合はGitHubアカウントとGitの利用を検討する

## このマニュアルの範囲

このマニュアルはローカルPC上での学習・開発用です。インターネットへの公開、独自ドメイン、HTTPS、バックアップ、監視などの本番運用は対象外です。`.env.example` のパスワードはローカル確認用なので、本番環境では使用しないでください。
