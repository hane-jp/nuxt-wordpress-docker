# 用語集

| 用語 | このプロジェクトでの意味 |
|---|---|
| ローカル環境 | インターネットへ公開せず、自分のPC上で動かす環境 |
| localhost | 自分のPC自身を表す名前。このプロジェクトでは `localhost:3000` と `localhost:8080` を使う |
| Docker | アプリの実行環境をコンテナとして揃える仕組み |
| Docker Desktop | macOSやWindowsでDockerを動かすためのデスクトップアプリ |
| イメージ | コンテナを作るためのひな型 |
| コンテナ | イメージから起動した、隔離された実行環境 |
| Docker Compose | 複数のコンテナを `docker-compose.yml` からまとめて起動する仕組み |
| ボリューム | コンテナを作り直しても残せるデータ保存領域 |
| WordPress | 投稿や画像を管理するCMS。この構成では主に管理画面とAPIを担当する |
| CMS | Webサイトのコンテンツを管理する仕組み |
| ヘッドレスCMS | CMSの管理機能と、閲覧者に見せる画面を分ける構成 |
| Nuxt | Vueを基盤にWeb画面を作るフレームワーク。この構成では閲覧側の画面を担当する |
| REST API | WordPressの投稿データをNuxtへJSON形式で渡す窓口 |
| リポジトリ | プロジェクトのファイルと変更履歴をまとめて管理する場所 |
| Git | ファイルの変更履歴をPC上で管理するツール |
| GitHub | Gitリポジトリをインターネット上で共有・管理するサービス |
| clone | Gitの履歴を含めてリポジトリをPCへ複製すること |
| ZIP | ファイルをまとめた圧縮形式。Gitの履歴は含まれない |
| `.env` | パスワードや接続先など、環境ごとに異なる設定を書くファイル |
| ターミナル | 文字でコマンドを入力し、PCを操作するアプリ |
| ポート | 同じPC内のサービスを区別する番号。この構成ではNuxtが3000、WordPressが8080 |
